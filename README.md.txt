# Medical Insurance Price Prediction

## Description
A Machine Learning web application that predicts medical insurance
price based on user details such as age, BMI, smoking habits, etc.

## Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML, CSS

## Project Structure
- app.py : Main Flask application
- insurance.csv : Dataset
- model_joblib_gr : Trained ML model
- templates/ : HTML files
- static/ : CSS and images

## How to Run
1. Install required libraries
2. Run app.py
3. Open browser and go to localhost

## Result
The model predicts insurance price with good accuracy.
